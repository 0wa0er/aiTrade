# aiTrade · A 股模拟交易台

本地运行的 A 股模拟盘，撮合规则向实盘对齐，支持定时任务自动盯盘、下单与复盘。

零外部依赖，只需要 Node.js ≥ 18。行情取自东方财富 / 新浪公开接口。

> **仅供策略演练与工程验证，不构成投资建议。**

## 它解决什么问题

多数模拟盘的问题在于**成交价失真**：按委托价立即成交、无滑点、涨停也能买进。用这种工具练出来的策略，换到实盘会因为成交价、费用、交易单位三处偏差而失效。

这个项目的取舍是：**宁可复杂一点，也要让成交价和费用接近真实**。

## 已对齐实盘的规则

| 维度 | 实现 |
|---|---|
| 交易时段 | 集合竞价 09:15–09:25（09:20 后不可撤）→ 连续竞价 09:30–11:30 / 13:00–14:57 → 收盘集合竞价 14:57–15:00（不可撤）→ 盘后固定价格 15:05–15:30（仅科创/创业） |
| 成交价 | 按五档**对手价**撮合，不再是委托价；支持部分成交 |
| 涨跌幅 | 主板 10% / 创业科创 20% / 北交所 30% / 主板 ST 5%；新股上市前 5 个交易日不设限 |
| 交易单位 | 主板、创业板、ETF 100 股整数倍；科创板 200 股起、1 股递增；北交所 100 股起、1 股递增 |
| 价格笼子 | 连续竞价限价申报：买 ≤ 基准×102%、卖 ≥ ×98%，与 ±10 个最小变动单位取宽，超出即废单 |
| 费用 | 佣金万 2.5（最低 5 元）、印花税千 0.5（仅卖出）、过户费万 0.1（双向），可按券商实际费率改 `data/fees.json` |
| 基金赎回费 | 持有期阶梯：< 7 天 1.5%、< 1 年 0.5%、< 2 年 0.25% |
| T+1 | 当日买入不可卖，按交易日切换（周末与节假日不重置） |
| 除权除息 | 现金分红入账、送转加股、成本摊薄；红利税按持有期在卖出时补扣 |
| 涨跌停 | 涨停无卖盘、跌停无买盘时**真的成交不了**，不是只做价格校验 |

## 账户权限（最容易被忽略的一层）

模拟账户按**新开户**设定：5 万本金、无交易经验。券商的实际门槛是「资产 + 交易经验」**双条件**——即使钱够，创业板也开不了，因为要求 24 个月交易经验。

| 板块 / 品种 | 当前 | 开通条件 |
|---|---|---|
| 沪深主板 | 可交易 | 无 |
| 场内基金（ETF / LOF） | 可交易 | 无 |
| 创业板 | 禁止 | 20 日日均资产 10 万 + 24 个月经验 |
| 科创板 | 禁止 | 20 日日均资产 50 万 + 24 个月经验 |
| 北交所 | 禁止 | 20 日日均资产 50 万 + 24 个月经验 |
| 可转债 | 禁止 | 10 万 + 24 个月经验 |
| ST / 风险警示板 | 禁止 | 签署风险警示股票风险揭示书 |
| 退市整理期 | 禁止 | 50 万 + 24 个月经验 + 风险揭示书 |
| 公募 REITs | 禁止 | 签署基础设施基金风险揭示书 |
| 两融 / 港股通 / 期权 / 新三板 | 禁止 | 50 万起，另有经验与考试要求 |

拦截点有三处：命令行闸门（`cli.js`）、服务端下单接口（`server.js`，含网页手动下单）、候选池筛选（`scan` 自动剔除）。**只拦买入** —— 卖出永远放行，否则权限收紧后存量持仓退不出来。

**一个容易搞混的地方**：科创 50ETF（588000）、创业板 ETF（159915）是**场内基金**，不受对应板块权限限制，可以正常买卖。代码段 688/300 是股票，588/159 是基金。

要放开某项：改 `data/autotrade.json` 的 `account.permissions`，即时生效，无需重启。

## 快速开始

```bash
node server.js          # 起服务，默认 http://127.0.0.1:5173
```

Windows 下双击 `start.bat` 亦可。首次启动会自动创建账户（`data/state.json`），默认本金 100 万；想要 5 万：

```bash
node cli.js reset 50000
```

## 命令行

`cli.js` 是为自动化准备的入口，**风控红线写在代码里而非提示词里**——提示词会漏，代码不会。

```bash
node cli.js status                      # 账户、时段、持仓、挂单
node cli.js risk                        # 风控信号（止损止盈线、超限告警）
node cli.js scan --limit 12             # 按成交额筛可买候选池
node cli.js quote 600900 512890         # 查行情
node cli.js buy 512890 12000 --dry-run  # 预检，不下单
node cli.js buy 512890 12000            # 市价买入
node cli.js sell 600900 400 --price 29.90
node cli.js orders                      # 未成交挂单
node cli.js cancel O000001              # 撤单
```

风控项（`data/autotrade.json`，改完无需重启）：单票上限、单笔下限、单日买入上限、持仓只数、现金底线、止损、止盈、禁 ST、禁场外基金、单价上限。

**注意最低佣金 5 元这个隐性成本**：单笔低于 1 万元时，实际佣金率会成倍上升。小资金账户里，这条比大资金刺眼得多。

## 日志体系

每次决策、成交、复盘都落盘到 `data/journal/YYYY-MM-DD.md`，按四个区块锚定：

```
账户快照 → 时间线（只增不改，按 HH:MM 排序） → 今日计划 → 收盘复盘
```

```bash
node cli.js note --tag 交易 "09:45 买入 512890 12000 份 @1.237"
node cli.js journal plan "..."            # 盘前写计划（覆盖）
node cli.js journal plan --append "..."   # 尾盘补明日预案（保留早盘计划）
node cli.js journal review "..."          # 收盘复盘
node cli.js journal brief --days 3        # 新会话开场摘要
```

时间线由程序按锚点插入，**不要手工编辑这些文件**。规范见 [`data/journal/README.md`](data/journal/README.md)。

定时任务之间彼此独立，不共享上下文——今天该做什么，全靠昨天写下的计划。所以 `AGENTS.md` 把「启动先读日志、结束必留痕」定成了硬约束。

## 目录结构

```
server.js            HTTP 服务 + 撮合核心 + 除权处理
core/rules.js        交易规则纯函数（时段/板块/单位/涨跌幅/笼子/费用）
core/journal.js      日志引擎（锚点分区、按时间插入、自动索引）
cli.js               命令行 + 风控闸门
public/              前端（原生 JS，图表用本地 echarts）
data/fees.json       券商费率
data/autotrade.json  自动交易的风控红线
data/journal/        业务日志（每日一篇）
test/                规则、护栏、日志三套用例
```

## 已知近似

做收益率结论前请先看这一段，否则容易把模拟结果当成真实能力。

- **撮合基于当前五档快照**，模拟不了排队的时间优先、逐笔成交、盘中临时停牌。打板与高频日内策略在此无效。
- 集合竞价按单一开盘价/收盘价全量成交，未模拟竞价过程中的部分成交。
- 无新股申购、两融、可转债、逆回购。
- `data/holidays.json` 目前只到 2026 年底，之后会退化为只认周末，每年年初需补一次。
- 行情接口为第三方公开接口，无可用性保证。
