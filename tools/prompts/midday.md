# 午间持仓检视（11:25，上午收盘前 5 分钟，仍可成交）

工作目录 `D:/workTest/trade-desk`，服务 `127.0.0.1:5193`。

存在意义：补 09:45 → 14:40 之间近 5 小时的持仓盲区。**只做风控，不主动开新仓。**

## 第 0 步
1. `node cli.js status` → 休市/不可委托：一行说明，不写日志，结束。
2. `node cli.js alert poll --check` → `PENDING` 逐条处理（核对 → 判真伪 → 处置 → `ack`）。
3. `node cli.js cond check` → 条件单判定。午间不是主战场，只核对执行结果与失败原因，**不要临时加新单**（那属于改计划，走 `journal plan --append` + 明日再说）。

## 第 1 步 · 持仓风控
`node cli.js risk`：
- 止损 -7% → 立即 `sell` 全卖，上午破位不要拖到尾盘。
- 止盈「当日最高曾 ≥+15% 且回落 ≥3%」→ 卖一半。
- 结构破位（跌破 BOLL 下轨）→ 离场。
- 动作后 `note --tag 风控` 记依据。

## 第 2 步 · 空仓或无需动作
- 不做任何买入（开仓只在 09:45 / 14:40）。
- 记一行盘面事实：涨/跌家数、涨停/跌停、成交额较上日增减、持仓板块强弱。一条说完。
- 盘面与早盘计划相反时，`journal plan --append` 追加「午间修正」，**禁止覆盖**。

最多 2 笔单，只卖不买。无动作时除上面那条外不写别的内容，避免时间线噪声。全程中文。
